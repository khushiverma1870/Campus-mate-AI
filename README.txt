CAMPUS MATE AI - VS CODE PROJECT

Files:
- index.html : Page structure and app sections
- style.css  : Colors, layout, cards, responsive design
- script.js  : Attendance, tasks, timetable, notes, Study Buddy logic

HOW TO RUN:
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Right-click and choose "Open with Live Server" if you have the Live Server extension.
   OR open index.html directly in Chrome/Edge.
4. No build command, Android Studio, or OpenAI API key is required.

NOTE:
This is a browser-based prototype. It stores data in localStorage on the current browser/device.
The Study Buddy uses predefined rule-based replies; it is not connected to a live AI model.
